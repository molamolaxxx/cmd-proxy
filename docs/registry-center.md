# 注册中心与远程环境

Starweave 可以把当前进程注册到另一个 Starweave。中心页面的环境列表会出现该远程环境，切换后，配置、聊天、团队、任务、调度及文件操作由目标进程执行。中心仅保存路由元数据与连接状态，转发请求和响应，不运行远程 Agent、不复制会话或附件、不接管调度。

## 使用

1. 在中心的「系统设置 → 注册中心服务器」中，打开「启用注册中心」开关，按需设置隧道端口（默认 `10530`）。设置立即保存，应用内的 Netty 隧道随之启动，无需下载额外程序。
2. 中心显示「运行中」后，在接入端的同一设置区域填写中心管理页面的 `IP:端口` 或 `https://域名:端口`及环境名称，点击上传图标。环境名称默认填入当前实例 ID，可直接修改；点击注册后保存。
3. 接入端显示「已注册」后，中心的环境选择器可切换到这个环境。中心只登记接入端的当前进程，同机其它环境不会一起注册。

接入端需能连接中心的管理页面端口和隧道端口。本地无需公网 IP 或开放入站端口。中心每个环境使用一个 `20000～29999` 范围内的内部代理端口，仅绑定 `127.0.0.1`，无需对外开放这些内部端口。公网管理入口建议通过 HTTPS 访问；Netty 隧道强制使用 TLS。

注册设置独立保存，点击注册或应用图标立即生效，不必使用全局「保存并应用」。接入端、中心重启后自动恢复连接。取消注册会停止隧道，中心保留环境条目并标记离线。离线请求明确报错，不会落到中心自身环境。代理不自动重放业务写请求，避免消息或任务重复创建。

接入端可在同一区域设置可选的「环境访问密码」，随注册一起保存，也可点击密码旁的保存按钮单独修改。中心切换到设有密码的环境时会弹窗验证；验证通过前，配置、聊天、文件和其它管理接口拒绝代理操作。浏览器自动保存 7 天登录状态，到期后重新验证；环境重启不会清除有效登录，修改密码会使旧登录立即失效。移除密码后恢复免密码访问。密码采用带随机盐的 PBKDF2 摘要保存，不回传密码或摘要；浏览器只保存带签名且有期限的 HttpOnly 登录 Cookie。

## 包与数据边界

- `acp.registry`：注册客户端、中心控制接口、配置持久化、远程环境目录和生命周期。
- `acp.registry.tunnel`：应用内 Netty 反向隧道、TLS、控制连接及数据流生命周期。
- `acp.configui.EnvironmentHttpProxy`：本机与远程环境共用的 HTTP 字节流代理，保留状态码、必要请求/响应头及文件内容，及时刷新 SSE。
- 现有主机级 `InstanceRegistry` 继续负责本机实例冲突检查。远程环境不参与本机文件锁、数据目录或 RPC 端口冲突判断。

每个环境的数据目录下新增 `registry/`：

| 文件 | 用途 |
| --- | --- |
| `config.json` | 中心/客户端设置、节点身份 |
| `environments.json` | 中心登记的远程环境元数据；不保存有效连接租约 |

注册无需填写凭证。隧道令牌与连接租约由程序自动交换；相关配置和日志在支持 POSIX 权限的系统上设为仅文件所有者可读写。远程环境标识由中心生成，与源实例标识分开，避免跨主机同名冲突。在线状态只有在中心通过隧道核验目标实例身份后才成立；租约与连接标识防止旧连接回调影响新连接。

中心目前最多登记 100 个环境。注册中心管理和实例列表始终属于接收请求的进程；系统设置接口和业务接口跟随当前选择的环境。外部调用方直接使用的独立网关、RPC 或其它监听端口不自动映射，本功能覆盖 ConfigUI 的管理操作。

## Netty 隧道

隧道直接运行在 Starweave JVM 中，使用 Netty NIO 和 JDK TLS，不启动外部进程。中心在内存中生成自签名证书，通过注册接口将公钥证书返回接入端；接入端使用该证书校验隧道服务端。注册接口应使用 HTTPS，以保护初始令牌及证书交换。

接入端维持一条带心跳的 TLS 控制连接。中心收到本机代理请求后，通过控制连接通知接入端创建独立的 TLS 数据连接，接入端仅连接当前进程的回环 ConfigUI 端口。双方按字节流转发，支持文件和 SSE，不缓存完整 HTTP 请求；读取节奏跟随对端写入，限制单环境并发数据流和等待时间。隧道握手校验令牌、环境租约及已分配端口，连接代次防止旧连接影响新连接。

此协议与旧 frp 隧道不兼容，中心与接入端需要一起更新。旧版本留下的 frp 配置、日志和运行时文件不再使用，升级不会自动删除它们。证书和私钥只驻留内存，不产生新的隧道配置文件。

## 验证

```bash
mvn -pl cmd-proxy-app -Dtest=RemoteEnvironmentRegistryTest,RegistryManagerTest,EnvironmentHttpProxyTest test
node --test cmd-proxy-app/src/test/js/registry.test.js
# 真实 TLS 反向隧道测试，无需外网
mvn -pl cmd-proxy-app -Dtest=NettyRegistryIntegrationTest test
```

真实隧道测试覆盖无凭证接入、在线登记、二进制传输、中心重启后的自动恢复及取消注册，纳入常规 Maven 回归。
